PACIO Announcements

  • May 19, 2024

    The PACIO Project successfully tests and demonstrates how the Standardized Medication Profile (SMP) IG and an early draft of the Transitions of Care Implementation Guide can be used to exchange a patient's transitions of care information necessary by many post-acute care disciplines.

  • May 19, 2024

    The PACIO Project successfully tests and demonstrates how the Advance Directives (ADI) Implementation Guide can be used to exchange structured Personal Advance Care Plans (PACPs), unstructured Portable Medical Orders (PMOs), and unstructured Mental Health Advance Directives (MHAD). A video of the demonstration is available.

  • February 29, 2024

    The PACIO Project successfully tests and demonstrates how the Personal Functioning and Engagement (PFE), Physical Activity, and Gravity Social Determinants of Health Clinical Care (SDOH-CC) Implementation Guides can be used to enable data relevant to post-acute care during the PACIO Testing Event. The testing follows the patient through their care journey through a tightly-coupled use case and be available for decision making by the patient and their caregivers and family. A video of the demonstration is available.

  • January 11, 2024

    The PACIO Advance Directive Interoperability (ADI) implementation guide was published as STU-1 (Standard for Trial Use 1). View the published ADI implementation guide here: PACIO Advance Directive Interoperability Implementation Guide 1.0.0 - STU1

  • January 5, 2024

    The PACIO Personal Functioning and Engagement (PFE) implementation guide was published as STU-1 (Standard for Trial Use 1). View the published PFE implementation guide here: PACIO Personal Functioning and Engagement Implementation Guide 1.0.0 - STU1

  • September 28, 2022

    The PACIO Re-Assessment Timepoints implementation guide was published as STU-1 (Standard for Trial Use 1). View the published Re-Assessments Timepoints implementation guide here: PACIO Re-Assessment Timepoints Implementation Guide 1.0.0 - STU1

  • November 3, 2021

    The PACIO Cognitive Status implementation guide was published as STU-1 (Standard for Trial Use 1).

  • November 3, 2021

    The PACIO Functional Status implementation guide was published as STU-1 (Standard for Trial Use 1).
